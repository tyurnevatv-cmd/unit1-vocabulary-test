GRAMMAR TO USE

1. First Conditional

Real / possible future situation

If + Present Simple, will + infinitive

If the enemy attacks, the unit will launch a counterattack.

2. Second Conditional

Imaginary / unlikely present or future situation

If + Past Simple, would/could + infinitive

If the unit had greater mobility, it could maneuver more quickly.

3. Third Conditional

Imaginary past situation

If + Past Perfect, would/could have + V3

If the engineer battalion had cleared the obstacle, the infantry would have advanced faster.

4. Mixed Conditional

Past cause + present result

If + Past Perfect, would/could + infinitive

If the vehicles had received proper maintenance, the unit would have greater mobility now.

5. Subjunctive Mood

recommend / insist / order that + subject + infinitive without to

The commander recommends that the signal battalion restore communication.

It is important / essential that + subject + infinitive without to

It is essential that every unit maintain communication.

Passive: that + subject + be + V3

The commander insists that the vehicles be checked immediately.

Important: after if, do not use will or would in these conditional patterns.
